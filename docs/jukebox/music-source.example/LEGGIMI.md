# Una cartella della musica, per esempio

Qui c'è solo `album.json`: nel repo non va mai musica. La cartella completa, con brani e copertine fatti con dei numeri
(liberi, di nessuno), la scrive il builder:

```bash
python -m tools.jukebox demo --out C:\Users\<te>\Moon\musica-demo
```

Come è fatta e come si usa: `docs/jukebox/README_ADMIN.md`.
