	   item only adds what it names (Item has no reset), so these bodies add the parts and change nothing else.

	   The parts hang on each weapon model's own "muzzle" point (ModelWeaponPart = part model self parent). No weapon
	   model is written here: a second body of a model resets it before loading (ScriptType Model has ResetExisting,
	   ModelScript.reset clears mesh, texture and scale), and the game reads its own scripts before the mods', so the
	   guns would lose their mesh. In 42.21 "muzzle" turns the frame (-90 0 0 on the pistols, -90 0 +-180 on the long
	   guns); each part's own "canon" point turns it back (SilencerMoon_models.txt), so a part sits exactly where Simple
	   Suppressors put it (the muzzle offset, unturned). The game composes parent point x part point, never inverted. */
